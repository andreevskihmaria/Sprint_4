# Юнит-тесты BooksCollector

Юнит-тесты класса `BooksCollector` — приложения для учёта книг: добавление книг, присвоение жанров, фильтрация по жанру и возрастному рейтингу, работа со списком избранного. Первый проект по автоматизации тестирования на pytest.

## О проекте

Тестируемый класс `BooksCollector` хранит книги со жанрами и список избранного. Правила, которые нужно было проверить:

- название книги — от 1 до 40 символов, иначе книга не добавляется;
- жанр присваивается только из фиксированного списка: «Фантастика», «Ужасы», «Детективы», «Мультфильмы», «Комедии»;
- книги с жанрами «Ужасы» и «Детективы» имеют возрастной рейтинг и не попадают в подборку для детей;
- одна и та же книга не добавляется в избранное дважды.

Ключевые решения:

- **Каждый тест создаёт свой экземпляр `BooksCollector`.** Общей фикстуры с состоянием нет намеренно: тесты не влияют друг на друга и могут запускаться в любом порядке.
- **Границы диапазона проверяются параметризацией.** Название из 0 символов и название из 41 символа — два кейса одного теста, а не два почти одинаковых метода.
- **Проверяются оба направления правила.** Для подборки детских книг есть и тест «книги без рейтинга попадают в список», и тест «книги с рейтингом в него не попадают». Проверка только позитивного случая пропустила бы дефект, при котором в список попадает всё подряд.

## Что покрыто тестами

**Добавление книг**

| Тест | Проверка |
|------|----------|
| `test_add_new_book_add_two_books` | Две разные книги успешно добавляются в словарь |
| `test_add_new_book_with_invalid_name_does_not_add_book` | Книга не добавляется, если название пустое или длиннее 40 символов — 2 кейса |

**Жанры**

| Тест | Проверка |
|------|----------|
| `test_set_book_genre_an_existing_genre` | Существующий жанр присваивается книге |
| `test_set_book_genre_does_not_exist_genre` | Жанр не из списка книге не присваивается |
| `test_get_book_genre_book_exists` | Жанр существующей книги возвращается по её названию |
| `test_get_books_with_specific_genre_returns_books_with_needed_genre` | Возвращается список книг только запрошенного жанра |
| `test_get_books_genre_returns_current_books_dictionary` | Возвращается актуальный словарь книг и жанров |

**Возрастной рейтинг**

| Тест | Проверка |
|------|----------|
| `test_get_books_for_children_returns_children_books` | Книги без возрастного рейтинга попадают в детскую подборку |
| `test_get_books_for_children_does_not_include_age_rating_books` | Книги жанров «Ужасы» и «Детективы» в детскую подборку не попадают — 2 кейса |

**Избранное**

| Тест | Проверка |
|------|----------|
| `test_add_book_in_favorites_book_exists` | Существующая книга добавляется в избранное |
| `test_add_book_in_favorites_book_doesnt_exist` | Несуществующая книга в избранное не добавляется |
| `test_add_book_in_favorites_add_double_book` | Повторное добавление той же книги не создаёт дубликат |
| `test_delete_book_from_favorites_book_exists` | Книга удаляется из избранного |
| `test_get_list_of_favorites_books_two_books` | Возвращается актуальный список избранного |

Итого **14 тестовых функций**, которые с учётом параметризации дают **16 тест-кейсов**.

## Структура проекта

```text
.
├── main.py                     # Тестируемый класс BooksCollector
├── test_books_collector.py     # Тесты
└── requirements.txt
```

Класс `BooksCollector` в `main.py` предоставлен Яндекс Практикумом как объект тестирования. Моя работа — файл с тестами.

## Требования

- Python 3.10 или новее

## Установка и запуск

```bash
git clone https://github.com/andreevskihmaria/books-collector-unit-tests.git
cd books-collector-unit-tests
python -m venv venv
```

Активировать окружение — Windows:

```bash
venv\Scripts\activate
```

macOS и Linux:

```bash
source venv/bin/activate
```

Установить зависимости и запустить тесты:

```bash
pip install -r requirements.txt
pytest -v
```

Посмотреть, как раскрываются параметризованные кейсы:

```bash
pytest -v --collect-only
```

## Результаты

Все правила класса `BooksCollector` ведут себя согласно ожиданиям, дефектов не обнаружено.

Что оказалось важным по ходу работы:

- **Файл с тестами должен называться так, чтобы pytest его нашёл.** Изначально файл назывался `tests.py`, и команда `pytest` собирала ноль тестов: по умолчанию pytest ищет файлы по маскам `test_*.py` и `*_test.py`, а `tests.py` под них не подходит. Запуск работал только при явном указании файла. После переименования в `test_books_collector.py` тесты собираются автоматически.
- **Границы важнее середины.** Проверка названия из 20 символов не даёт почти ничего, а вот пустая строка и 41 символ — именно те значения, на которых ломается условие `0 < len(name) < 41`.
- **Метод `add_new_book` не сообщает об ошибке.** При некорректном названии он молча ничего не делает, поэтому проверять нужно не возвращаемое значение, а состояние коллекции после вызова.
